# v2.0.0 release notes

## Changes from v1.0.0

Choose a native archive by CI provider and target. The GitHub Actions binary
provides the existing fourteen GitHub commands. The Azure Pipelines binary
provides thirteen writers covering variables, PATH, diagnostics, masking,
build metadata, log groups, summaries and files. Both executables are called
`shoutx` and report the same version. See the [Azure writer selection guide](../../README.md#choose-a-writer)
for usage and the [compatibility record](../compatibility/azure-pipelines.md)
for supported environments and observed limits.

## Installation changes

The major version marks an incompatible archive filename and archive root.
For example, Linux x86-64 uses `shoutx-github-actions-v2.0.0-x86_64-unknown-linux-musl.tar.gz`
or `shoutx-azure-pipelines-v2.0.0-x86_64-unknown-linux-musl.tar.gz`.
Update direct downloads and extraction paths, verify the selected archive against
this release's SHA256SUMS, and install its native executable. The [release
contract](../release.md#artifact-contract) specifies all platforms and the manifest.

The v0.1.0 setup action supports the older layout. Use a reviewed installer
commit with revision 2 support or its v0.2.0 release once published.
Ordinary Cargo source builds still enable both providers. The GitHub Actions
command syntax and destination contracts carry forward from v1.0.0.

See [GitHub Releases](https://github.com/send/shoutx/releases) for publication
status and the immutable release assets.
