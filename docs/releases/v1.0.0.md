# v1.0.0 release notes

Version 1.0.0 was [published](https://github.com/send/shoutx/releases/tag/v1.0.0)
on 2026-10-17 from `946e55388e513ed411c31ca292d49379115dfd7e`.
The [publication and verification record](https://github.com/send/shoutx/pull/131#issuecomment-6231099782)
retains the release identity, artifact checks and installation results.

v1.0.0 is the first stable CLI baseline for practical GitHub Actions output
boundary coverage. It is not a claim to implement every Runner operation or
protect an entire workflow. See the [coverage inventory](../design.md#v1-readiness)
and [CLI compatibility baseline](../design.md#v1-cli-compatibility-baseline).

## Changes from v0.3.0

- Add `github-actions:artifacts file` and `artifacts oci` for typed declarations
  in `$GITHUB_ARTIFACTS`. These declare subjects; they do not upload files or
  authorize paths, references or digests. See the [artifact contract](../commands/github-actions-artifacts.md).
- Add `github-actions:debug`, `group` and `endgroup` for typed log operations.
  Callers still own group lifetime and the safety of other process output.
  See the [log-command contract](../commands/github-actions-log-commands.md).
- Add `github-actions:add-matcher` and `remove-matcher`, including explicit
  file/owner removal modes. These frame requests, not authorize matcher files,
  owners or regexes. See the [matcher contract](../commands/github-actions-problem-matchers.md).
- Harden release publication around one verified draft ID and retries; update
  archive-validator dependencies and CI/static-analysis tooling.
- Update the reviewed test consumer to Runner v2.338.0 with SDK 8.0.425 and
  runtime 8.0.31. This does not control the version of GitHub-hosted Workers.

The default and official builds expose all fourteen commands. Existing
output/env/state/path/mask/notice/warning/error invocation and encoding contracts
are unchanged from v0.3.0. This release does not widen Unicode acceptance,
silently sanitize values, add decoration, or add raw passthrough. Existing
v0.3.0 invocations need no syntax migration; new commands require v1.0.0 or a
source build. Previously published binaries are not changed.

## Compatibility and installation

The [consumer profiles](../design.md#stdout-adoption-contract), including the
separate [artifact scope](../design.md#artifact-consumer-scope), still apply.
Binary target availability is not a promise of support for every self-hosted
Runner, culture, OS generation or surrounding workflow. Review the
[current compatibility record](https://github.com/send/shoutx/blob/main/docs/compatibility/stdout-unicode-policy.md)
before adoption; installed binaries cannot detect later consumer changes.

Native targets and setup-action artifact contract revision 1 are unchanged.
Follow the [installation instructions](../../README.md#installation) with
`shoutx-version: '1.0.0'`
with the same pinned setup action, or verify and install its exact native
archive. An independently pinned checksum manifest must come from v1.0.0;
do not reuse a v0.3.0 digest. There is no crates.io/package-manager publication.
